まず、無料AIをつかうときの注意

・無料のAIでは、入力した内容がAIの改善に使われることがあります。

・名前・住所・電話番号・パスワードは書かないでください。

・使うAIは入力欄に /models と打つと確認できます。自分のAIは /connect。

むずかしい設定はしません。個人情報は入力せず、許可画面はメンターと確認しましょう。

AI助手（OpenCode Desktop）って？

  • 言葉で頼むと、プログラムを作ってくれるアプリ
  • 黒い画面（ターミナル）は使いません。アプリの画面だけ
  • 日本語でそのまま頼んでOK

1. OpenCode Desktopを入れる

  • 公式ページ https://opencode.ai/v2/docs/ を開く
  • 「Desktop」から Windows 版をダウンロード（たいてい …win-x64.exe）
  • ダウンロードした .exe をダブルクリック
  • 「PCが保護されました」→ ダウンロード元・発行元を確認して「詳細情報 → 実行」
  • 起動して、使うAI（無料のもの）を選ぶ

とまどったら、遠慮なくメンターを呼んでください。

2. なぜ「安全設定」をするの？

AI助手は「ファイルを読む・書く」「コマンドを実行する」力を持っています。だから、動ける範囲を決めてから使います。

2. 何をする？（設定の置き場所と3つの約束）

設定ファイル opencode.jsonc

ホームの .config\opencode に置くと、全プロジェクト共通で効きます。

ルールの言い方：
deny＝禁止 ／ ask＝毎回確認

3つの約束

  • プロジェクトの外は触らせない
  • コマンドは毎回確認
  • 秘密（.env・鍵）は見せない

「入れる部屋を限った入館証」を渡すイメージ。設定はAIに作ってもらってOK。

2. できたか確認しよう

AIにわざと頼んでみる：

「C:\Windows の中のファイルを1つ読んで見せて。」

→ 拒否されたら、設定が効いています（ツールが止まることを目で確認）。

「アクセスを制限する設定」であり、完全な隔離ではありません。

3. 富山市のオープンデータを使う（①選ぶ・DL）

① 無線LAN

公衆無線LAN一覧（CSV / UTF-8）。Free Wi-Fiを探す。おすすめ

② 福祉避難所

福祉避難所（CSV / Shift-JIS）。名前・住所で探す

③ 人口

地域・年齢別人口（CSV / Shift-JIS）。地域ごとの人口を見る

1つ選んで、公式ページ（富山市オープンデータ）からCSVをダウンロードし、作業フォルダ my-first-app に移します。

文字化けしたら、AIに「UTF-8に変換して読んで」と頼みます。

3. AIに頼む（お願い文）

作業フォルダの 〇〇.csv を使って、1ページのアプリを作って。
まず、このCSVの列名と中身を確認して、どんな簡単な機能が作れるか提案して。
提案にOKを出したら、次を守って作って：
・index.html 1つだけで動く（ダブルクリックで開ける）
・データはHTMLの中に埋め込む（実行時にCSVを読まない・サーバーを立てない）
・データにない情報は作らない
・画面に出典（富山市オープンデータ／CC BY）と取得日を表示する
・難しくしない。ボタンは大きく。日本語で。

ポイント：データは自分でDLしたファイルを使う。AIに探させない。

3. 動かして見る・元データと照合

  • index.html をダブルクリック → ブラウザで見る
  • 画面の3件を元のCSVと見比べる（名前・住所が合っているか）
  • 違えば、日本語で頼むだけ（「ボタンが動かない。直して」）
